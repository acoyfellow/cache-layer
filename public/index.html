Architecture

Prototype locally. Deploy on Cloudflare.

The public deployment runs on a Cloudflare Worker with Workers AI available for conservative route confirmation. Local evaluation can use Ollama on public OSS or dummy data.

Safety boundary

Read-only first.

May route

Public documentation, public test-output summaries, and bounded repository status workflows.

Must escalate

Edits, deploys, comments, secrets, private code, customer data, and security judgment.
